# Realm Onboarding Guidance（自助开通强指引与首登引导）用户故事

> 角色定义见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)
> 与既有 `US-SR-001`~`US-SR-004`（[core/realm-create.md](realm-create.md)，已发布）的关系：本组故事只覆盖「入口曝光」与「首登引导」两层体验，不重复定义自助开通能力本身。

## 用户故事

### 故事 1：访客在平台门面登录页看到自助开通强指引 [US-OG-001]

**优先级**: P0

**【用户故事】**
**作为**：SaaS 自助注册访客（未登录访客，详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md) persona 别名表）
**我希望**：在 admin realm 登录页看到醒目的「开通自己的 Realm」引导区块，说明平台价值并给出开通入口
**从而**：在登录页就知道正确路径是自助开通自己的 realm，而不是误注册成平台门面里的普通账号后面对无用的一亩三分地

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：开关开启时强指引可见**
```gherkin
Given 平台自助开通开关已开启
And 我是未登录访客，访问 admin realm 的登录页
When 登录页呈现
Then 我看到一个突出的自助开通引导区块，包含平台价值摘要与「开通自己的 Realm」入口
And 我点击该入口后进入自助开通注册页
```

**场景 2：开关关闭或状态不可得时不渲染（fail-closed）**
```gherkin
Given 平台自助开通开关已关闭（或开关状态查询失败）
And 我是未登录访客，访问 admin realm 的登录页
When 登录页呈现
Then 不出现自助开通引导区块
And 登录表单及其他既有功能正常可用
```

**场景 3：register 入口降级为弱化次级链接**
```gherkin
Given 平台自助开通开关已开启
And 我是未登录访客，访问 admin realm 的登录页
When 登录页呈现
Then 「注册普通账号(register)」以弱化的次级文字链接形式呈现，视觉与文案层级明显低于自助开通引导区块
And 点击该链接仍可进入既有普通账号注册页
```

**场景 4：非 admin realm 登录页不受影响**
```gherkin
Given 我是未登录访客
When 我访问某个非 admin realm 的登录页
Then 不出现平台自助开通引导区块
And 该页既有的登录与注册入口呈现规则不变
```

### 故事 2：新 realm 管理员首登获得价值引导 [US-OG-002]

**优先级**: P0

**【用户故事】**
**作为**：刚通过自助开通注册的新 realm-admin（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md) persona 别名表）
**我希望**：注册成功直达我的 realm 管理控制台时，系统用营销式新手引导向我说明核心功能与价值，并给我一份可随时回到的新手任务清单
**从而**：理解这个控制台能帮我完成什么、核心能力各在哪里，而不是面对空控制台直接流失

**【验收标准】**

**场景 1：signup 成功直达后引导出现**
```gherkin
Given 我刚通过自助开通成功，系统把我带入新 realm 的管理控制台
When 控制台首次呈现
Then 出现欢迎引导，以平台核心卖点（如权限模型、积分与钱包、支付收款、第三方登录对接等）组织的营销式说明
And 提供新手任务清单与控制台功能漫游入口
And 引导界面文案跟随我的界面语言（英文或简体中文）
```

**场景 2：完成或主动关闭后不再自动出现**
```gherkin
Given 我已完成引导，或在我主动关闭了引导
When 我刷新页面，或退出后再次登录进入该 realm 的管理控制台
Then 引导不再自动出现
```

**场景 3：从任务清单重新进入未完成的引导**
```gherkin
Given 我此前关闭过引导，且管理控制台存在新手任务清单
When 我在控制台打开任务清单并选择继续功能漫游
Then 我可以从清单重新发起功能漫游
```

**场景 4：换设备或清缓存后重现一次且可关闭**
```gherkin
Given 我曾在某一浏览器上完成过该 realm 的引导
When 我更换设备或清除浏览器数据后首次进入该 realm 的管理控制台
Then 引导重新出现一次
And 我可以立即关闭它并继续正常使用控制台
```

### 故事 3：既有 realm 管理员首次进入控制台获得同等引导 [US-OG-003]

**优先级**: P1

**【用户故事】**
**作为**：Realm Admin（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：首次进入本 realm 的管理控制台时，也看到与自助开通路径一致的新手引导
**从而**：不通过自助开通路径进入的管理员，与自助开通的管理员拥有相同的功能认知起点

**【验收标准】**

**场景 1：非 signup 路径首次进入控制台触发引导**
```gherkin
Given 我是某个既有 realm 的管理员，且当前浏览器未记录过我在该 realm 完成引导
When 我首次进入该 realm 的管理控制台
Then 出现与 US-OG-002 场景 1 相同形态的新手引导
```

**场景 2：完成后同一 realm 不再自动出现**
```gherkin
Given 我已在该 realm 完成或主动关闭过引导
When 我再次进入该 realm 的管理控制台
Then 引导不再自动出现
```

## 与既有故事的关系

- **承接 `US-SR-001`（自助注册开通新 Realm）**：US-OG-001 解决的是该能力「零曝光」的问题——能力与页面已发布（`docs/prd/core/realm-create.md`），本故事只在其前增加登录页指引层。
- **承接 `US-SR-002`（开通后立即管理新 Realm）**：US-OG-002 在「直达管理控制台」这一步之后增加价值引导层，不改变直达行为本身（DEC-realm-create-012）。
- **引导对象边界**：仅 realm 管理员，不含普通终端用户首登（DEC-realm-onboarding-guidance-004）。
