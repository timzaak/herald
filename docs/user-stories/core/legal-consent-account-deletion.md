## 普通用户（Regular User）

### 故事 11：注册时同意用户协议与隐私政策 [US-RU-011]

**优先级**: P0

**【用户故事】**
**作为**：普通用户（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：在注册时阅读并同意所属 Realm 当前生效的用户协议与隐私政策
**从而**：在知情前提下获得系统访问权限，满足合规要求

**【验收标准】**

**场景 1：勾选同意并继续注册**
```gherkin
Given Realm realm-1 已开启注册
And 存在当前生效的用户协议与隐私政策
When 用户填写注册信息并勾选"我已阅读并同意《用户协议》与《隐私政策》"
And 提交注册
Then 注册流程按现有注册规则继续
And 系统记录该用户已同意当前协议版本
And 《用户协议》《隐私政策》为可点击查看的链接
```

**场景 2：未勾选同意阻止注册**
```gherkin
Given 用户在注册页面
When 未勾选同意复选框就提交注册
Then 系统提示"请阅读并同意用户协议与隐私政策"
And 注册不继续
```

**场景 3：协议链接可查看**
```gherkin
Given 用户在注册页面
When 点击《用户协议》或《隐私政策》链接
Then 在新页面或弹层展示所属 Realm 当前生效的协议全文
```

### 故事 12：协议更新后重新同意 [US-RU-012]

**优先级**: P0

**【用户故事】**
**作为**：普通用户（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：当所属 Realm 的用户协议或隐私政策更新后，能再次知情并选择是否继续同意
**从而**：保证我的同意始终针对最新条款，满足"知情同意"合规要求

**【验收标准】**

**场景 1：协议更新后登录触发重新同意**
```gherkin
Given 用户此前已同意旧版本协议
And 所属 Realm 的协议发布了新版本
When 用户登录或访问受保护功能
Then 系统提示协议已更新并展示新版本内容
And 用户可选择同意或拒绝
```

**场景 2：同意新版本后继续使用**
```gherkin
Given 用户处于协议更新提示中
When 用户勾选同意新版本并确认
Then 系统记录用户对新版本的同意
And 用户继续正常使用
```

**场景 3：拒绝新版本**
```gherkin
Given 用户处于协议更新提示中
When 用户拒绝同意新版本
Then 用户无法继续使用需要同意的核心功能
And 系统提供退出登录入口与注销账户入口
```

**场景 4：已同意最新版不重复提示**
```gherkin
Given 用户已同意当前最新版本协议
When 用户登录或访问功能
Then 不再弹出协议更新提示
```

**场景 5：更新对已登录用户的影响**
```gherkin
Given 用户已登录且正在使用系统
And 所属 Realm 协议发布了新版本
When 用户后续访问需要同意的核心功能
Then 系统提示协议已更新并要求重新同意
And 用户当前进行中的非核心操作不被强制中断
```

### 故事 14：自助注销账户（软删除） [US-RU-014]

**优先级**: P0

**【用户故事】**
**作为**：普通用户（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：能够自助注销我的账户，且注销后我的个人身份信息不再被识别
**从而**：行使被遗忘权，同时账户以软删除方式保留合规与审计必要的数据

**【验收标准】**

**场景 1：注销成功**
```gherkin
Given 用户已登录
When 用户从个人中心进入"注销账户"
And 完成二次确认
Then 账户进入注销态，无法再登录
And 当前所有登录会话立即失效
And 用户的个人身份信息（邮箱、昵称、密码等）被匿名化、不再可识别
And 系统保留账户骨架与合规/审计必要的最小数据
And 生效中的订阅被联动取消
And 注销操作被记录到审计日志
```

**场景 2：注销需二次确认**
```gherkin
Given 用户在注销账户页面
When 未完成二次确认就尝试提交
Then 系统要求完成确认，阻止误操作
```

**场景 3：注销后原凭证无法登录**
```gherkin
Given 用户账户已注销
When 用户使用原邮箱与密码尝试登录
Then 系统提示账号已注销或凭证无效
And 登录失败
```

**场景 4：注销不可逆**
```gherkin
Given 用户账户已注销
When 用户希望恢复账户
Then 系统不支持自助恢复（无宽限期）
```

**【备注】**
- 关联数据处理：注销时立即失效所有会话与已签发 Token、解绑 OAuth 第三方账号绑定、清除 TOTP 二次认证配置、联动取消生效中的订阅。
- 一次性购买（如积分包等）已交付的不予退款，注销不触发退款。
- 注销后该邮箱能否重新注册，属跨域待确认项，不在本故事验收内固定。

Given 用户此前已同意旧版本协议

## 域管理员（Realm Admin）

### 故事 19：管理本 Realm 的用户协议与隐私政策 [US-RA-019]

**优先级**: P1

**【用户故事】**
**作为**：域管理员（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：查看与编辑本 Realm 的用户协议与隐私政策（覆盖平台默认模板），并管理其版本
**从而**：为本 Realm 的用户提供符合自身业务的合规条款，且条款更新可追溯

**【验收标准】**

**场景 1：查看本 Realm 当前协议**
```gherkin
Given Realm Admin 已登录
When 进入 Settings 的协议管理 Tab
Then 展示本 Realm 当前生效的用户协议与隐私政策
And 标识当前展示的是"平台默认模板"还是"本 Realm 自定义"
```

**场景 2：编辑并发布自定义协议**
```gherkin
Given Realm Admin 在协议管理 Tab
When 编辑用户协议或隐私政策文本并保存发布
Then 本 Realm 生效文本切换为该自定义版本
And 发布构成一次版本变更，已同意旧版的用户需重新同意
```

**场景 3：回退到平台默认模板**
```gherkin
Given Realm Admin 已设置自定义协议
When 选择清除自定义并回退默认
Then 本 Realm 生效文本恢复为平台默认模板
And 视为版本变更，触发用户重新同意
```

**场景 4：跨 Realm 隔离**
```gherkin
Given Realm A 的 Realm Admin
When 尝试查看或编辑 Realm B 的协议
Then 操作被拒绝
```

**场景 5：协议版本变更被审计**
```gherkin
Given Realm Admin 发布或回退协议
When 操作完成
Then 该变更记录到本 Realm 审计日志
```

**场景 6：发布产生新版本并留存历史**
```gherkin
Given Realm Admin 编辑协议并发布
When 发布完成
Then 产生新的协议版本
And 历史版本被保留可查
And 已同意旧版的用户需重新同意
```

**场景 7：平台默认模板更新触发未覆盖 Realm 重新同意**
```gherkin
Given 某 Realm 未自定义协议，使用平台默认模板
And 平台默认模板更新为新版本
When 该 Realm 用户下次登录或访问核心功能
Then 被提示协议已更新，需重新同意
```
