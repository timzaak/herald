# Regular User 用户故事（refund-clawback）

> 角色定义见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)

## 用户故事

### 故事 1：多次部分退款按每笔增量回收积分 [US-RC-001]

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：一笔充值发生多次部分退款时，每次退款只按该笔退款金额占原支付的比例回收对应积分
**从而**：退款后我的积分余额准确反映实际退款比例，不会因多次退款被重复扣减

**【验收标准】**

**场景 1：两笔部分退款累计回收对齐累计退款比例**
```gherkin
Given 我充值 1000（最小货币单位）获得 10000 积分且未消费
When 支付方对这笔充值先后推送金额为 300 和 200 的两笔部分退款
Then 系统累计回收 5000 积分（累计退款 50% 对应的授予额度）
And 我的积分余额为 5000
```

**场景 2：回收不超过该来源未消费余额**
```gherkin
Given 我充值 1000 获得 10000 积分且已消费 6000，剩余 4000
When 支付方对这笔充值推送一笔 500 的部分退款
Then 系统最多回收剩余的 4000 积分，回收后该来源余额为 0 且不出现负数
And 我从其他来源（订阅、免费发放、管理员发放）获得的积分不受影响
```

**场景 3：同一笔退款重复推送不二次回收**
```gherkin
Given 支付方的一笔退款已被系统处理并完成积分回收
When 同一笔退款被支付方重复推送（重试或重发）
Then 系统不产生二次回收，我的积分余额不变
```

**场景 4：累计退款达到全额时回收全部剩余**
```gherkin
Given 我充值 1000 获得 10000 积分，这笔充值已发生 30% 部分退款且回收已执行
When 支付方再推送一笔退款使这笔支付的累计退款达到 1000（全额）
Then 系统回收该来源全部剩余积分，余额为 0
```

### 故事 2：部分退款保留一次性购买角色 [US-RC-002]

**优先级**: P1

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：我的一次性购买发生部分退款时保留该购买授予的角色，仅当这笔支付被累计全额退款时才回收角色
**从而**：商家的善意部分补偿不会剥夺我已购买的永久权益，同时全额退款仍防止权益被白嫖

**【验收标准】**

**场景 1：部分退款保留角色，积分照常按比例回收**
```gherkin
Given 我通过一次性购买获得永久角色和 10000 积分
When 支付方对这笔支付推送一笔 300 的部分退款（原支付 1000）
Then 系统按比例回收 3000 积分
And 该笔购买授予我的永久角色保留
And 管理员手工授予的同名角色不受影响
```

**场景 2：累计退款达到全额时回收角色**
```gherkin
Given 我的一次性购买已发生累计 60% 的部分退款且角色仍保留
When 支付方再推送一笔退款使这笔支付的累计退款达到 100%
Then 系统回收该来源全部剩余积分
And 该笔支付来源的永久角色被撤销
```

**场景 3：多次部分退款未达全额时角色持续保留**
```gherkin
Given 我的一次性购买已发生累计 60% 的部分退款且角色保留
When 支付方再推送一笔使累计退款达到 90% 的部分退款
Then 系统继续按该笔增量比例回收积分
And 我的永久角色仍保留
```

**场景 4：争议/撤销事件不触发角色回收、保留不失效**
```gherkin
Given 我的一次性购买授予的永久角色因部分退款被保留
When 支付方推送该笔支付的争议或撤销事件（非退款）
Then 系统不因该争议事件回收该角色（一次性购买的争议事件不触发回收）
And 部分退款的角色保留不因争议事件失效
```

**【备注】**
- 订阅退款触发的角色撤销不适用本故事，维持既有行为（见 [support-paywall.md](support-paywall.md) US-PW-005 场景 1/2）。
- 本故事细化 US-PW-005 场景 4 的「退款即回收一次性永久角色」表述：退款半句改为仅累计全额退款回收（DEC-refund-patch-002）。
- 场景 4 钉住现状（DEC-refund-patch-005）：争议/撤销事件不触发一次性购买的角色回收；「争议事件回收一次性角色」的能力缺口另立方案解决，不属于本故事范围。
