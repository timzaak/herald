# 免费用户积分用户故事

> 角色定义见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)

## 用户故事

### 故事 1：注册时获得初始积分 [US-FU-001]

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：注册时自动获得初始积分
**从而**：可以立即体验产品功能，无需付费

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：注册时自动获得初始积分**
```gherkin
Given 我是新用户
When 我完成注册（2026-03-23 15:30:00 UTC）
Then 我自动获得 1000 注册初始积分
And 积分类型为注册初始积分
And 积分永久有效
And 系统显示欢迎消息："恭喜！您已获得 1000 初始积分"
```

**场景 2：查看注册初始积分详情**
```gherkin
Given 我已注册并获得初始积分
When 我在"我的积分"页面查看积分明细
Then 我看到积分分类显示：
  | 积分类型 | 余额 | 有效期 |
  | 注册初始积分 | 1000 | 永久有效 |
And 我看到积分来源为 "注册赠送"
And 我看到获得时间为注册时间
```

**场景 3：防止重复获取注册初始积分**
```gherkin
Given 我已注册并获得初始积分
When 我尝试再次注册（使用相同邮箱）
Then 系统显示错误："该邮箱已被注册"
And 我不会再次获得注册初始积分
```

**场景 4：注册初始积分可用于消费**
```gherkin
Given 我有 1000 注册初始积分（永不过期）和 50 免费定期积分（今天过期）
When 我消耗 100 积分
Then 系统优先扣除即将过期的定期积分 50，再扣除注册初始积分 50
And 我剩余 950 注册初始积分和 0 免费定期积分
And 交易记录显示消费类型为"消耗"
And 消费分配记录显示：
  | 积分类型 | 消费金额 | 剩余金额 |
  | 免费定期积分 | 50 | 0 |
  | 注册初始积分 | 50 | 950 |
```

### 故事 2：定期自动获得免费积分 [US-FU-002]

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：按配置周期自动获得免费积分（支持一次性/每日/每周/每月）
**从而**：可以持续使用产品基础功能

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：注册后立即获得第一批定期积分（Daily 周期）**
```gherkin
Given 我是新用户
And Realm 配置免费用户周期类型为 "daily"
When 我完成注册（2026-03-23 15:30:00 UTC）
Then 我立即获得 50 免费积分
And 积分类型为免费定期积分
And 积分有效期为 1 天（明天 15:30 过期）
And 系统显示消息："您已获得今日 50 积分，明天 15:30 到期"
```

**场景 2：次日同一时间自动发放（Daily 周期）**
```gherkin
Given 我已于 2026-03-23 15:30:00 UTC 注册
And Realm 配置免费用户周期类型为 "daily"
When 时间到达 2026-03-24 15:30:00 UTC
Then 系统自动发放 50 免费积分
And 新积分明天 15:30 过期
And 昨天的 50 积分同时过期
And 我的免费定期积分余额保持 50（不累积）
```

**场景 3：每周发放一次（Weekly 周期）**
```gherkin
Given 我已于 2026-03-23 15:30:00 UTC 注册（周一）
And Realm 配置免费用户周期类型为 "weekly"
And 每周发放 200 积分，有效期 7 天
When 时间到达 2026-03-30 15:30:00 UTC（下周同一时间）
Then 系统自动发放 200 免费积分
And 新积分 7 天后过期（2026-04-06 15:30）
And 上周的 200 积分同时过期
And 我的免费定期积分余额保持 200
```

**场景 4：每月发放一次（Monthly 周期）**
```gherkin
Given 我已于 2026-03-23 15:30:00 UTC 注册（3月23日）
And Realm 配置免费用户周期类型为 "monthly"
And 每月发放 500 积分，有效期 30 天
When 时间到达 2026-04-23 15:30:00 UTC（下月同一天）
Then 系统自动发放 500 免费积分
And 新积分 30 天后过期（2026-05-23 15:30）
And 上月的 500 积分同时过期
And 我的免费定期积分余额保持 500
```

**场景 5：一次性发放（Once 周期）**
```gherkin
Given 我是新用户
And Realm 配置免费用户周期类型为 "once"
And 配置发放 100 积分，有效期 7 天
When 我完成注册（2026-03-23 15:30:00 UTC）
Then 我立即获得 100 免费积分
And 积分类型为免费定期积分
And 积分 7 天后过期（2026-03-30 15:30）
And 系统不会再次发放
And 我的免费定期积分余额为 100
```

**场景 6：定期积分不累积**
```gherkin
Given 我今天有 50 免费积分（今天 23:59 过期）
And 我今天只使用了 20 积分
When 时间到达明天 00:00（假设周期为 daily）
Then 系统发放新的 50 积分
And 昨天剩余的 30 积分已过期
And 我的免费定期积分余额为 50（不是 80）
```

**场景 7：查看定期积分发放历史（Daily 周期）**
```gherkin
Given 我已注册 7 天
And Realm 配置免费用户周期类型为 "daily"
When 我在"我的积分"页面查看交易历史
Then 我看到 7 条定期积分发放记录：
  | 日期 | 积分类型 | 金额 | 过期时间 |
  | 2026-03-23 | 免费定期积分 | 50 | 2026-03-24 15:30 |
  | 2026-03-24 | 免费定期积分 | 50 | 2026-03-25 15:30 |
  | ... | ... | ... | ... |
  | 2026-03-29 | 免费定期积分 | 50 | 2026-03-30 15:30 |
And 我看到每笔积分都按注册时间点发放（15:30）
```

**场景 8：查看即将过期的定期积分**
```gherkin
Given 我今天有 50 免费积分
And 过期时间为今天 23:59
When 我在"我的积分"页面查看
Then 我看到过期提醒："您有 50 积分将于今天 23:59 过期"
And 过期提醒用橙色高亮显示
```

**场景 9：跨时区用户积分发放**
```gherkin
Given 我在东八区（北京）注册
And 注册时间为 2026-03-23 23:30:00 UTC（北京时间 07:30）
And Realm 配置免费用户周期类型为 "daily"
When 时间到达 2026-03-24 23:30:00 UTC（北京时间 07:30）
Then 系统自动发放 50 免费积分
And 前端显示本地时间："2026-03-25 07:30 (Asia/Shanghai)"
```

### 故事 3：升级到付费套餐时保留注册初始积分 [US-FU-003]

**优先级**: P1

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：升级到付费套餐时保留我的注册初始积分
**从而**：升级不会损失我的积分资产

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：升级前查看积分状态**
```gherkin
Given 我是免费用户
And 我有 1000 注册初始积分（永久）
And 我有 50 免费定期积分（今天有效）
When 我在"我的积分"页面查看
Then 我看到积分分类显示：
  | 积分类型 | 余额 | 有效期 |
  | 注册初始积分 | 1000 | 永久有效 |
  | 免费定期积分 | 50 | 今天 15:30 过期 |
And 我的总余额为 1050
```

**场景 2：升级到付费套餐**
```gherkin
Given 我是免费用户
And 我有 1000 注册初始积分
And 我有 50 免费定期积分（今天有效）
When 我订阅 "pro-monthly" 付费套餐
Then 系统立即回收我的免费定期积分 50
And 系统停用我的免费定期积分调度
And 注册初始积分 1000 保留
And 系统立即发放付费积分 100（有效期从升级时刻重新计算）
And 我的总余额 = 1100（注册 1000 + 付费 100）
And 我看到交易记录显示：回收免费定期积分 50，发放付费积分 100
```

**场景 3：升级后积分分类**
```gherkin
Given 我已升级到付费套餐
When 我在"我的积分"页面查看
Then 我看到积分分类显示：
  | 积分类型 | 余额 | 有效期 |
  | 注册初始积分 | 1000 | 永久有效 |
  | 付费订阅积分 | 100 | 从升级时刻重新计算 |
And 免费定期积分已归零（已回收）
And 我看到注册初始积分永久保留
And 我看到交易记录：免费定期积分回收 50，付费积分发放 100
```

**场景 4：升级后取消付费订阅**
```gherkin
Given 我已升级到付费套餐
And 我有 1000 注册初始积分
And 我有 500 付费积分（未过期）
When 我取消付费订阅（立即取消）
Then 系统回收 500 付费积分
And 注册初始积分 1000 保留
And 免费定期积分调度保持停用状态
And 我的总余额 = 1000（仅注册初始积分）
```

**场景 5：升级后重新订阅**
```gherkin
Given 我已升级到付费套餐后又取消
And 我有 1000 注册初始积分
When 我再次订阅付费套餐
Then 注册初始积分 1000 继续保留
And 系统创建新的付费积分调度
And 系统立即发放付费积分
```

### 故事 4：按时获得每期免费积分（不受分发延迟影响） [US-FU-004]

> 本故事的前提（逐期预发 + 分发延迟）已被 `US-FU-005` 的懒发放/滚动窗口模型取代。保留原文仅作历史参考，产品意图以 `US-FU-005` 为准。

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：每期免费积分在周期开始时按时到账，不因系统调度延迟而漏发或迟发
**从而**：能稳定使用产品基础功能，不会在应得积分的时间点拿不到积分

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：后续每期免费积分按时到账（Daily 周期）**
```gherkin
Given 我已于 2026-03-23 15:30 注册
And Realm 配置免费用户周期类型为 "daily"，每期 50 积分
When 时间到达 2026-03-24 15:30（下一周期开始）
Then 我按时获得本期 50 免费积分
And 上一期未用完的积分按预期时间过期，不累积
```

**场景 1.1：后台调度未及时运行时，请求时同步补发**
```gherkin
Given 我已于 2026-03-23 15:30 注册
And Realm 配置免费用户周期类型为 "daily"，每期 50 积分
And 免费积分后台调度尚未及时运行
When 时间已经到达 2026-03-24 15:30（下一周期开始）
And 我查看积分余额或发起积分消费
Then 系统同步补发本期 50 免费积分
And 本期免费积分立即可见且可消费
And 我不会因为后台调度延迟而拿不到本期免费积分
```

**场景 2：提前发放使到账不晚于周期开始**
```gherkin
Given 系统在周期开始前已为我预先发放本期免费积分（尚未到生效时间）
And 分发链路存在延迟
When 时间到达本期周期开始
Then 本期积分已就绪可消费
And 我不会因分发延迟在本期周期开始时拿不到积分
```

**场景 3：本期积分在生效前不可见、不可消费**
```gherkin
Given 系统已预先发放本期免费积分（周期尚未开始）
When 我在周期开始前查看余额或尝试消费
Then 预先发放的积分对我不可见、不可消费，不计入我的余额
When 时间到达本期周期开始
Then 该积分变为可见且可消费
```

### 故事 5：免费周期积分改为滚动窗口配额 [US-FU-005]

> 本故事承载"积分发放策略重设计（points-grant-redesign）"的新模型意图；其前提（懒发放、滚动窗口、不累积随窗口释放）取代了故事 4（US-FU-004）基于"逐期预发 + 分发延迟"的旧前提。

**优先级**: P0

**【用户故事】**
**作为**：Regular User（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：我的免费周期额度按滚动时间窗口实时可用（注册即得、用不完不累积、超额可继续用我的注册或充值余额），升级付费后免费额度立即停止
**从而**：免费体验稳定、不因系统发放延迟断顿，且升级后不会新旧额度混用

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：注册即得窗口额度（不依赖后台预发）**
```gherkin
Given Realm 为免费用户配置了滚动窗口免费额度（如每日窗 50）
When 我完成注册并立即访问积分余额或首次消费
Then 我立即获得当前窗口内可用的免费额度
And 我不依赖系统后台的预先发放或定时调度即可使用
```

**场景 2：免费额度随窗口滚动释放（不累积）**
```gherkin
Given 我在某窗口内只使用了部分免费额度（每日窗 50，已用 20）
When 对应时间窗口滑过（例如进入下一个滚动窗口区间）
Then 我未使用的额度不会累积到新窗口
And 新窗口内我重新获得该窗口的完整额度上限
```

**场景 3：多时间窗限额取最小值**
```gherkin
Given 我的免费额度配置了多个时间窗限额
And 我在某个较短窗口内已用满
When 我查看当前可用免费额度
Then 当前可用免费额度为各时间窗剩余中的最小值
And 较短窗口用满时，即使较长窗口仍有剩余，当前可用免费额度也为 0
```

**场景 4：免费额度不足时继续使用注册/充值余额**
```gherkin
Given 我当前免费窗口可用额度为 30
And 我有注册初始积分 1000
When 我消费 100 积分
Then 系统先扣完免费窗口额度 30
And 剩余 70 自动从注册初始积分扣减
And 操作一次性成功
```

**场景 5：升级到付费套餐后免费窗口额度停止**
```gherkin
Given 我是免费用户并享有免费窗口额度
When 我升级到付费套餐
Then 我的免费窗口额度立即停止（不再产生新的免费可用额度）
And 我的注册初始积分保留
And 我开始享受付费套餐的额度
```
