# Realm Admin 用户故事（billing-statistics）

> 角色定义见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)

与既有已发布故事的关系：US-BS-001 承接 US-PV-005（支付平台使用统计）中"笔数/成功率/金额"的平台汇总视角并移入统一统计页；US-BS-002 补齐 US-PO-007（免费用户积分统计）未覆盖的通用积分**消耗**视角。US-PV-005 的 Active Subs / Avg Payment Time 与 US-PO-007 的发放/转化统计不在本文件范围。

## 用户故事

### 故事 1：查看支付统计总览 [US-BS-001]

**优先级**: P1

**【用户故事】**
**作为**：Realm Admin（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：在管理后台查看本 Realm 的支付统计总览（成功/失败笔数、成功率、按币种与渠道分组的支付金额、按日趋势）
**从而**：无需逐笔翻阅购买流水即可掌握本 Realm 的收入规模与支付健康度

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：查看支付统计总览**
```gherkin
Given 我是 realm-1 的管理员
And realm-1 最近 7 天内产生了 12 笔成功支付（Stripe 10 笔 USD、WeChat Pay 2 笔 CNY）和 3 笔失败支付
When 我访问计费统计页的支付统计面板
Then 我看到成功支付笔数 12、失败支付笔数 3、支付成功率 80%（12/15）
And 我看到支付金额按币种分组展示：USD 与 CNY 分别显示各自合计
And 页面任何位置都不出现把 USD 与 CNY 相加得到的总金额
And 我看到按支付渠道（Stripe、WeChat Pay 等）分组的笔数与金额
And 我看到按日聚合的成功/失败支付趋势图，横轴为日期，无支付的日期显示为 0
```

**场景 2：切换时间窗口**
```gherkin
Given 我在支付统计面板，当前时间窗口为"最近 7 天"
When 我切换为"最近 30 天"
Then 指标与趋势图刷新为最近 30 天的数据
And 页面明确显示当前生效的时间窗口
```

**场景 3：新 Realm 空态**
```gherkin
Given realm-1 是新创建的 Realm，尚无任何支付记录
When 我访问支付统计面板
Then 指标显示 0，趋势图显示"暂无数据"，页面不报错
```

**场景 4：无支付数据查看权限**
```gherkin
Given 管理员账号 A 属于 realm-1，未被授予支付数据查看权限（billing.view）
And A 持有积分查看权限（points.view）
When A 访问计费统计页（即使 URL 指向支付面板）
Then 支付统计面板静默不渲染、不出现「拒绝/无权限」提示——页面回退呈现积分消耗统计面板
And A 看不到任何支付统计数据
```

> 权限呈现口径（与实现一致）：单侧权限缺失→对应面板/Tab 静默不渲染并回退到有权限的面板；`billing.view` 与 `points.view` 均缺失→整页显示无权限提示。

### 故事 2：查看积分消耗统计 [US-BS-002]

**优先级**: P1

**【用户故事】**
**作为**：Realm Admin（详见 [docs/user-stories/_roles.md](/docs/user-stories/_roles.md)）
**我希望**：在管理后台查看本 Realm 的积分消耗统计（总消耗量、有消耗行为的用户数、按积分账户分组的消耗量、按日趋势）
**从而**：了解积分开销的分布与随时间的变化，判断积分成本与用量走势

**【验收标准】**

> 验收标准只描述用户动作与可见结果，不写 API 路径、数据表、字段变更、技术实现步骤。

**场景 1：查看积分消耗总览**
```gherkin
Given 我是 realm-1 的管理员
And realm-1 配置了"注册初始积分"与"充值积分"两个积分账户
And 最近 7 天内用户通过两个账户分别消耗了 5,000 与 20,000 积分，共涉及 30 个不同用户
When 我访问计费统计页的积分消耗统计面板
Then 我看到窗口内总消耗 25,000 积分、有消耗行为的用户数 30
And 我看到按积分账户分组的消耗量："注册初始积分"5,000 与"充值积分"20,000 分列展示
And 我看到按日聚合的消耗趋势图，横轴为日期，无消耗的日期显示为 0
```

**场景 2：切换时间窗口**
```gherkin
Given 我在积分消耗统计面板，当前时间窗口为"最近 7 天"
When 我切换为"最近 30 天"
Then 指标与趋势图刷新为最近 30 天的数据
```

**场景 3：退款回收不计入消耗**
```gherkin
Given 我是 realm-1 的管理员
And realm-1 有一笔充值支付发生退款，系统按未使用比例回收了该用户 500 积分
When 我查看该时间窗口的积分消耗统计
Then 消耗统计不包含这 500 的回收量
And 回收不作为负数冲减任何消耗指标
```

**场景 4：新 Realm 空态**
```gherkin
Given realm-1 尚无任何积分消耗记录
When 我访问积分消耗统计面板
Then 指标显示 0，趋势图显示"暂无数据"，页面不报错
```

**场景 5：无积分数据查看权限**
```gherkin
Given 管理员账号 A 属于 realm-1，未被授予积分查看权限（points.view）
When A 尝试访问积分消耗统计面板
Then 系统拒绝并提示无权限，A 看不到任何积分消耗统计数据
```
